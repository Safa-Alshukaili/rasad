# رصد (Rasad) — نظام موحّد لبلاغات الخدمات الحكومية

نظام Full-Stack يتيح للمواطن تقديم بلاغ عن مشكلة خدمية (طريق، مياه، كهرباء، نفايات) بلغته الطبيعية، يصنّفه تلقائياً بالذكاء الاصطناعي، يعرضه على خريطة تفاعلية، ويحلل الأنماط الجغرافية لتحديد المناطق ذات المشاكل المتكررة.

---

## 📌 الفكرة

الأنظمة الحكومية التقليدية لتلقي البلاغات غالباً نماذج تعبئة ثابتة تحتاج تصنيف يدوي من الموظف. **رصد** يقدّم بديل: المواطن يكتب المشكلة بكلامه العادي، والنظام:

1. يصنّفها فوراً (Claude API) إلى الجهة المسؤولة
2. يحدد موقعها على خريطة (GeoJSON)
3. يحلل البلاغات المتراكمة لإبراز "مناطق ساخنة" تحتاج تدخل استباقي

الذكاء الاصطناعي هنا **مساعد لا يحل محل القرار البشري** — كل تصنيف تلقائي يبقى علّمه "مبدئي" (`categoryConfirmed: false`) حتى يراجعه ويؤكده موظف.

---

## 🛠 التقنيات

**Frontend:** React, Redux Toolkit, React Router, Leaflet (خرائط), Recharts (مخططات)
**Backend:** Node.js, Express, MongoDB + Mongoose, JWT للمصادقة
**AI:** Anthropic Claude API لتصنيف نص البلاغ

---

## ✨ الميزات

- تسجيل دخول حقيقي بـ JWT (وليس فقط إرسال بيانات المستخدم بدون حماية)
- دوران بصلاحيات: مواطن (يقدّم بلاغ) / موظف (يدير ويصنّف)
- تصنيف تلقائي للبلاغ بالذكاء الاصطناعي عند الإرسال
- رفع صورة مع البلاغ، مع تحقق من نوع وحجم الملف
- تحديد الموقع تلقائياً (Geolocation API) وحفظه كـ GeoJSON
- خريطة تفاعلية تعرض كل البلاغات
- لوحة تحكم للموظف: إحصائيات، تصفية، تغيير الحالة والتصنيف
- تحليل "مناطق ساخنة": مناطق فيها 3+ بلاغات بآخر 30 يوم
- تحقق من الملكية: لا يمكن لمستخدم حذف أو تعديل بلاغ غيره

## 🔒 الأمان (الفرق الجوهري عن مشروع VOX السابق)

| نقطة | VOX (المشروع السابق) | رصد (هذا المشروع) |
|---|---|---|
| المصادقة | لا يوجد — الفرونت إند يرسل `userId` مباشرة | JWT حقيقي، السيرفر يستخرج هوية المستخدم من التوكن |
| الحذف/التعديل | أي شخص يعرف الـ id يقدر يحذف | تحقق من الملكية (`req.user.id === resource.owner`) قبل أي تعديل |
| رفع الملفات | يقبل أي امتداد وحجم | حد 5MB + امتدادات صور فقط |
| محاولات الدخول | غير محدودة | Rate limiting (10 محاولات / 15 دقيقة) |
| أسرار الاتصال | `.env` مرفوع فعلياً على GitHub | `.env.example` بدون قيم حقيقية + `.gitignore` |

## ▶️ التشغيل المحلي

### 1. السيرفر
```bash
cd server
npm install
cp .env.example .env
# عدّلي القيم بملف .env (رابط MongoDB الخاص بك ومفتاح JWT_SECRET عشوائي)
npm run dev
```

### 2. الواجهة
```bash
cd client
npm install
cp .env.example .env
npm start
```

التطبيق يفتح على `http://localhost:3000`
